# Contract integration

Sepolia contract:
`0x10bb66634d453ad417ee1c66811ea0c8636dc2be`

The frontend uses the supplied ABI in `abi.json`.

Integrated methods include `balances`, `deposit`, `withdraw`, `transferFunds`, `frozen`, `freezeWallet`, `unfreezeWallet`, `owner`, `getContractBalance`, `totalDeposits`, `totalWithdrawals`, `totalTransfers`, `addTrustedContact`, `removeTrustedContact`, and `trustedContacts`.

The exact Solidity source is not reconstructed from the ABI. Use the authoritative source and an independent security review before any mainnet deployment.
